# 🕐 桌面时钟 DesktopClock

一款简洁大气的 **Windows 桌面时钟挂件**。显示公历、农历、星期、节日、节气、天气。内存占用小（约 24MB 私有内存），无需安装任何运行环境，双击即用。

![桌面时钟运行截图](screenshot.png)

## ✨ 功能特性

- 🕐 **大字时间**：可开关秒；时间文字渐变 + 阴影，支持 28–240 号字号
- 📅 **公历 + 星期 + 农历**：农历、干支、生肖一应俱全
- 🎏 **节日 / 节气徽章**：农历节日、公历节日、清明、24 节气，当天自动显示徽章
- 🌤 **天气**：来自中国天气网（免费、无需 Key），每 30 分钟自动刷新；实时温 + 高低温 + 风向风力 + 湿度
- 🎨 **高度可定制**：字体（含开源字体包）、字号、颜色、强调色、背景色、背景透明度，**实时预览**
- 📐 **布局灵活**：8 个位置预设 + 记住当前位置；**位置锁定**、**置顶**、**鼠标穿透**
- ⚙️ **运行管理**：开机自启、托盘图标、右键菜单、双击托盘打开设置
- 🧩 **字体扩展**：把任意 `.ttf` 放进 `fonts` 文件夹即自动出现在字体列表

## 🖱 用法

| 操作 | 功能 |
|---|---|
| **左键拖动** | 移动时钟（位置自动记住；锁定后不可拖） |
| **右键单击时钟** | 打开菜单：设置 / 锁定 / 置顶 / 穿透 / 天气 / 自启 / 退出 |
| **右键托盘图标** | 同右键菜单 |
| **双击托盘图标** | 打开设置 |

## ⚙️ 设置（实时预览）

- **外观**：字体预设（简洁 / 经典 / 楷书 / 黑体 / 仿宋 / 等线 / 快乐），时间字体与信息字体独立选择，时间字号，文字 / 强调色 / 背景色，背景透明度，显示秒
- **布局**：8 个位置预设 + 记住当前位置；位置锁定；置顶；鼠标穿透
- **天气**：显示开关，常用城市下拉（40+ 城市自动补全），支持**搜索城市名**自动查城市码，也可手动输入城市名 + 城市码
- **常规**：开机自启

## 🌤 天气

- 数据来自 **中国天气网**（免费，无需 Key），30 分钟自动刷新
- 三种选城市方式：常用城市下拉 / 搜索城市名 / 手动输入城市码
- 网络异常时天气行自动隐藏，**不影响时钟显示**

## 📂 项目结构

```
DesktopClock/
├── DesktopClock.exe       ← 程序本体（双击即用）
├── src/                   ← 源码
│   ├── Program.cs         ← 主程序（界面/逻辑/设置）
│   ├── Calendar.cs        ← 农历/节气算法
│   └── Test.cs            ← 农历算法自检
├── scripts/               ← 构建与安装脚本
│   ├── build.bat          ← 编译 DesktopClock.exe
│   └── make-icon-from-clock.ps1  ← 从 clock.png 生成 app.ico
├── fonts/                 ← 字体（放 .ttf 即出现在字体列表）
├── app.ico                ← 程序图标
├── clock.png              ← 图标源图
└── DesktopClock.ini       ← 配置文件（自动生成）
```

## 🔨 从源码构建

1. .NET Framework 4.x（Win10/11 通常自带）；
2. 双击 `scripts\build.bat`（用系统自带编译器 `csc.exe`，零额外依赖）；
3. 生成 `DesktopClock.exe`。

## 🛠 技术栈

- **语言/框架**：C#，WinForms（.NET Framework 4.x）
- **特色**：分层窗口（Layered Window）逐像素透明；GDI+ 抗锯齿渲染；纯 HTTP 天气数据规避 SSL 指纹屏蔽
